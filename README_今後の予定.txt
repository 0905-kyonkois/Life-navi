生活ナビ v0.35 — 今後の予定ページ

1. index.html を公開・起動してください。
2. メイン画面下部の「📅 今後の予定」を押すと専用ページが開きます。
3. 日付順／カレンダー表示、年・月切り替え、予定の追加・編集・削除に対応しています。
4. 推し活は薄ピンク、試験は薄赤、その他はグレーです。受付などはコンパクト表示が選べます。
5. 推し活予定に有効な関連URLを設定するとカード右側に「›」が出ます。その「›」から直接開けます。
6. Supabaseにログインすると今後の予定専用テーブルと同期します（初回は会話で確認した予定の初期データを登録）。未ログイン状態は初期データの表示のみです。
7. 日々のスケジュールは既存データを読み込みます。これまでの予定を削除・変更していません。日々のスケジュールの日付切り替え制限を解除しました。

注意：今後の予定は日々のスケジュールとは別管理です。この画面で編集した内容は日々のスケジュールへ自動反映されません。日々のスケジュールと完全双方向連携する機能は未実装です。
注意：公式ページのURLは未登録です。追加・編集からURLを設定してください。
注意：日程未定の英語Ⅱ・数学Ⅱ期末試験は専用ページにのみ表示されます。
